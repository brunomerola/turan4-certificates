verifier/CHANGES.txt -- every change made to the independent checkers when they were copied into this package
==================================================================================================================

The checkers were written in separate review sessions and used there to re-check the certificates. When they were
copied here, they were changed only where this was needed to run them from the package root, or to remove internal
references (internal review labels, internal task numbers, file paths of the private working repository).
No change touches the logic of a check; the only code changes are paths of input files (rv1_claim3.py, item 2;
rv2_dual.py, rv2_lift.py, rv2_decimals.py, item 5) and one printed label (rv2_dual.py, item 5).
This was verified mechanically: for every other Python file the abstract syntax tree with docstrings removed is
identical before and after, and rv_eval.c is identical after removing /* */ comments.
Items 1 to 4 describe the first version of the package; items 5 to 7 the programs added in the second version
(catalogue certificates, seven-vertex dual points of Table n7limits, independent check of the sharp N = 6
certificates); items 8 to 10 the third version (sigma(K_5^(4)) and the stability facts). In the third version two
small code changes go beyond paths, because the package does not contain two input files of the reviews: the
optional class list of rs_reps.py and the producer comparison of r_thm1.py (items 8 and 9). Item 11 describes the
fourth version, in which the certificates of Theorem main (b), (d), (e) were replaced by larger ones; there the
claimed values of rv2_dual.py and rv2_decimals.py that refer to these certificates (bounds, decimals, paths) were
updated, and nothing else. Items 12 and 13 describe the fifth version (Theorem sigmacat and Remark j4limit): the
checkers of the two J_4 reviews were renamed (prefixes jw_ and jd_) and the module names in their imports changed
accordingly; apart from that the code changes are paths of generated and input files. Two producer programs (prefix
sk_, not independent) check the new key lists.

6. Second version: a new independent checker, rv_sharp6.py
----------------------------------------------------------------------------------------------------------------
rv_sharp6.py     a3fdcf87b47353d47a4d20978b62228c8252e4496fe1d0e344fec45193ee4544
Written for this package from the paper's definitions (Definition cert) to check the sharp six-vertex certificates
of Remark n6sharp, which the first version could only check with the first implementation (verify_all.sh
--producer-n6). It imports nothing from search/ or from the other checkers, and its author did not read the first
implementation's checker. It has its own colex decoding (by sorting), edge order, flag identification (least sorted
edge list over the orderings of the non-roots), isomorphism classes (orbits over all 720 permutations), exact
LDL^T test with the product multiplied back, and evaluation from the definition; see its docstring. Negative
controls (a changed bound, a non-PSD Q, a doubled Q) are rejected (step sharp6_negative).

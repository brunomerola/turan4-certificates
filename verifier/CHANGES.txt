verifier/CHANGES.txt -- every change made to the independent checkers when they were copied into this package
==================================================================================================================

The checkers were written in separate review sessions and used there to re-check the certificates. When they were
copied here, they were changed only where this was needed to run them from the package root, or to remove internal
references (internal review labels, internal task numbers, file paths of the private working repository).
No change touches the logic of a check, with one exception: the path change in rv1_claim3.py (item 2 below).
This was verified mechanically: for every Python file the abstract syntax tree with docstrings removed is
identical before and after (rv1_claim3.py excepted), and rv_eval.c is identical after removing /* */ comments.

3. Arguments
----------------------------------------------------------------------------------------------------------------
No script needed new arguments. verify_all.sh passes:
* lambda = 2 to rv_reps.py as its second argument, and RV_LAM=2 in the environment of every other tool of part (a)
  (rv_prep.py, rv_eval, rv_compare.py, rv_pycheck.py) for K5_4minus and K6_4minus; RV_LAM=1 otherwise;
* OMP_NUM_THREADS (option --threads) to rv_eval;
* the certificate prefixes certificates/DIR/PREFIX (rv_prep.py, rv_pycheck.py, rv1_*.py append .cert.json and
  .cert.npz themselves);
* 30 random graphs to rv1_lift.py, as in the review.
All generated files (representatives, blobs, logs, giraud/, claim3/) go to the work directory (default work/).

4. Not copied
----------------------------------------------------------------------------------------------------------------
* The review's compiled binaries and generated tables (rv_eval binaries, reps_*.bin, blob_*.bin): verify_all.sh
  rebuilds them from rv_eval.c, rv_reps.py and rv_prep.py.
* A sampling plug-in on a Giraud-type construction (100,000 random 7-subsets; a sanity check of signs, mentioned in
  the paper's Section "Independent verification"), and the review's list scans of the producer's class lists: the
  class lists (137 MB) are not part of this package.
* Helper scripts of the reviews that are not needed for any statement of the paper: a mass-concentration side
  check of the dual point, a batch runner and comparison script that re-evaluated the 2,404 graphs of Giraud's law
  with the C evaluator (rv1_giraud.py evaluates them exactly in Python), and the extra cross-evaluators of the
  K_6^(4)- review.

search/CHANGES.txt -- changes made to the producer code when it was copied into this package
==================================================================================================================

The files of flagalg/ are copies of the producer code as it was run. Four files were edited to remove internal
references; all other files are byte-identical to the originals. Only paths.py changes code (a default path).
For the other three, the abstract syntax tree with docstrings removed is identical before and after.

* h44/gen.py, n6control/n6_control.py (docstring): an internal task number was removed.
* n7dual/lp_resolve.py, n7dual/paths.py (docstring): an internal item number was replaced by a description

* n7dual/paths.py (code): the default location of the large input files (class list, saved LP state) was an

  variable N7DUAL_MAIN_N7 still overrides it), and the comment above it was reworded. These input files are not
  included in the package.

Not copied: the producer's results, logs, data files and reports (only the final certificates are in
../certificates/), compiled caches (__pycache__, numba caches) and shell launchers.
